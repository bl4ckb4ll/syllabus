# syllabi

What do colleges actually make you read?

The repository root is the bookshelf. Each book is one top-level Markdown file.
There is no `books/` wrapper and no directory per book.

For now the corpus is deliberately narrow:

- philosophy
- English
- history

Nothing else is included merely because a university publishes a syllabus for it.

Book filenames should be useful at a glance rather than opaque identifiers. The
canonical filename is generated by:

`where would I read this and who would I read it with/tools/book-filename.grease`

For example:

`Dante - Inferno - $6 paper - free on Internet Archive.md`

The dollar amount in a filename is a derived summary of the most recent dated
price observation recorded inside the book file; it is not an undated claim that
the listing is still live. When the checked observation changes, regenerate the
filename. Internet Archive text is included only when a checked archive.org URL
is available. Missing price or archive information is simply omitted rather than
invented.

A top-level book record should say what the book is, describe it briefly, identify
the edition or ISBN actually assigned when known, link to Internet Archive/Open
Library discovery, record dated used-book price observations, and point to the
places where we found it being taught.

The only non-book directory is:

`where would I read this and who would I read it with/`

Everything relational or operational belongs there: colleges, departments,
courses, instructors, terms, syllabus evidence, Common Crawl run history, naming
tools, and other provenance. Those views should use symbolic links back to the
canonical top-level book files whenever that avoids duplication.

Syllabi are evidence, not the product. We do not need to mirror every PDF.

Price observations are dated. `abe used` in `isomorphisms/az` is the intended
AbeBooks lookup for the cheapest delivered used listing; an old observation is
never presented as a current price.

A missing syllabus, missing book, missing Internet Archive copy, or failed price
lookup stays explicit. Absence from one search is not evidence that the thing
does not exist.
