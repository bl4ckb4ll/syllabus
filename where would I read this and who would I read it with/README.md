# where would I read this and who would I read it with?

This tree answers questions about the books at repository root.

Planned views include:

- `colleges/`
- `departments/`
- `courses/`
- `instructors/`
- `terms/`
- `evidence/`
- `common-crawl-run-history/`

The canonical objects are the top-level books. When a college, department,
course, instructor, or term includes a book, prefer a Git symbolic link to that
book rather than another copy.

The first corpus is restricted to philosophy, English, and history. A search run
may inspect a broader university site, but material outside those three subjects
should not enter the bookshelf merely because it was discovered.
